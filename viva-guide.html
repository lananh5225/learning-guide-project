QUESTION 01

Why use semantic HTML tags instead of generic <div> elements?

Semantic elements such as <header>, <nav>, <main>, and <footer> describe the purpose of their content. This helps assistive technology and makes page structure easier to understand.

<header>
  <h1>Course notes</h1>
  <nav aria-label="Main navigation">...</nav>
</header>
QUESTION 02

What are the parts of an HTML table, and why separate <thead> and <tbody>?

A table uses <table> to contain rows, <tr> for each row, and <th> or <td> for header and data cells. Grouping rows in <thead> and <tbody> clarifies structure for styling and assistive tools.

<table>
  <thead><tr><th scope="col">Topic</th></tr></thead>
  <tbody><tr><td>HTML</td></tr></tbody>
</table>
QUESTION 03

What is an HTML attribute?

An attribute provides additional information or configuration for an element. It is written in the opening tag, often as a name and value pair. For example, href identifies a link destination and alt provides an image text alternative.

<a href="viva-guide.html">Study questions</a>
QUESTION 04

How do colspan and rowspan work in tables?

colspan makes a cell span multiple columns; rowspan makes it span multiple rows. Use them when a grouped heading or shared value genuinely describes the cells it covers.

<th colspan="2">Contact details</th>
QUESTION 05

How can HTML forms validate user input?

Choose an appropriate input type and use built-in attributes such as required, minlength, and min. Browser validation improves feedback, but applications should also validate data where it is processed.

<input type="email" name="email" required>
QUESTION 06

What is the CSS box model?

Each element is laid out as content surrounded by padding, border, and margin. With box-sizing: border-box, the declared width includes padding and border, making sizing more predictable.

* { box-sizing: border-box; }
QUESTION 07

How do you make a page responsive?

Use a viewport meta tag, flexible layouts, and media queries to adapt content to available screen space. Keep controls readable and avoid forcing users to scroll horizontally.

@media (max-width: 700px) {
  .layout { grid-template-columns: 1fr; }
}
QUESTION 08

What is the difference between HTTP GET and POST?

GET requests a resource and commonly carries query parameters in the URL. POST submits data for processing in the request body. Neither method by itself encrypts data; HTTPS protects data in transit.

QUESTION 09

How does JavaScript make a web page interactive?

JavaScript can respond to events, read or update the DOM, and change page state. For example, an event listener can respond when a user submits a form without embedding code directly in the HTML.

form.addEventListener("submit", handleSubmit);
QUESTION 10

What is a typical Git workflow for a web project?

Check the working tree, create or switch to a branch, make a focused change, review it, and commit with a descriptive message. Push the branch to share work and open a review before merging when collaborating.

git status
git add index.html
git commit -m "Update home page"
