Question 1: Why use Semantic HTML tags (<header>, <nav>, <main>, <footer>) instead of <div>?

1. Theoretical Foundation: Semantic tags convey explicit structural meaning to browsers, SEO crawlers, and screen readers.

2. Code Example:

<header><h1>Title</h1><nav><a href="#">Home</a></nav></header>

👨‍🏫 Instructor: "Why use <header> instead of <div class='header'>?"
👩‍🎓 Student: "It provides explicit semantic meaning for accessibility and SEO optimization."

Question 2: What are the core components of a standard HTML Table & why separate thead/tbody?

1. Theoretical Foundation: Separating header and body improves accessibility and allows precise CSS styling.

2. Code Example:

<table><thead><tr><th scope="col">ID</th></tr></thead><tbody><tr><td>1</td></tr></tbody></table>
