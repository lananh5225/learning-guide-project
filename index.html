📚 Part 1: 10 HTML Viva Questions & Answers

Question 1 Why use Semantic HTML tags (<header>, <nav>, <main>, <footer>) instead of <div>?

1. Theoretical Foundation:

Semantic tags convey explicit structural meaning to browsers, search engine crawlers (SEO), and screen readers, replacing anonymous container boxes like <div>.

2. Code Example:
<header><h1>Title</h1><nav><a href="#">Home</a></nav></header>
<main><section>Main content</section></main>
<footer><p>&copy; 2026</p></footer>
3. Common Pitfalls & Solutions:

Pitfall: Overusing generic <div> elements everywhere (Div soup). Solution: Replace structural blocks with proper semantic elements.

4. Simulated Viva Dialogue:

👨‍🏫 Instructor: "Why use <header> instead of <div class='header'>?"

👩‍🎓 Student: "It provides explicit semantic meaning for accessibility and SEO optimization."

Question 2 What are the core components of a standard HTML Table (CRUD Table) & why separate thead/tbody?

1. Theoretical Foundation:

Tables consist of <table>, <caption>, <thead>, <tbody>, <tr>, <th>, and <td>. Separating header and body improves accessibility and allows precise CSS targeting.

2. Code Example:
<table><caption>Data</caption><thead><tr><th scope="col">ID</th></tr></thead><tbody><tr><td>1</td></tr></tbody></table>
3. Common Pitfalls & Solutions:

Pitfall: Using <td> for headers. Solution: Always use <th scope="col">.

4. Simulated Viva Dialogue:

👨‍🏫 Instructor: "Why separate thead and tbody?"

👩‍🎓 Student: "It enables structured rendering and helps screen readers parse table coordinates accurately."

Question 3 What is the purpose of colspan and rowspan attributes in HTML tables?

1. Theoretical Foundation:

colspan merges cells horizontally across columns, while rowspan merges cells vertically across rows.

2. Code Example:
<tr><td colspan="2">Merged Columns</td><td rowspan="2">Merged Rows</td></tr>
3. Common Pitfalls & Solutions:

Pitfall: Miscalculating grid cell dimensions causing layout breakdown. Solution: Ensure row cell counts match total columns.

4. Simulated Viva Dialogue:

👨‍🏫 Instructor: "When do you use rowspan?"

👩‍🎓 Student: "When an event or category spans across multiple consecutive time slots or rows."

Question 4 What are the key attributes of <form> and the role of <label> paired with <input>?

1. Theoretical Foundation:

Forms use action and method to transmit data. Labels use for matching an input's id to enhance accessibility and usability.

2. Code Example:
<form action="/submit" method="POST"><label for="name">Name:</label><input id="name" name="name" required></form>
3. Common Pitfalls & Solutions:

Pitfall: Omitting the name attribute. Solution: Always verify matching id and name pairs.

4. Simulated Viva Dialogue:

👨‍🏫 Instructor: "Why associate a label with an input using the 'for' attribute?"

👩‍🎓 Student: "It links them for screen readers and allows users to click the text to focus the input field."

Question 5 Differentiate between GET and POST form submission methods.

1. Theoretical Foundation:

GET appends data to the URL query string (bookmarkable, public). POST transmits data securely inside the HTTP request body.

2. Code Example:
<form method="GET" action="search.html">...</form>
<form method="POST" action="login.php">...</form>
3. Common Pitfalls & Solutions:

Pitfall: Using GET for passwords or sensitive transactions. Solution: Always use POST for secure or state-changing actions.

4. Simulated Viva Dialogue:

👨‍🏫 Instructor: "When should you choose GET?"

👩‍🎓 Student: "For search queries where users benefit from bookmarking or sharing URLs."

Question 6 What layers make up the CSS Box Model, and what does box-sizing: border-box do?

1. Theoretical Foundation:

Layers: Content → Padding → Border → Margin. box-sizing: border-box includes padding and borders within the defined width/height.

2. Code Example:
*, *::before, *::after { box-sizing: border-box; }
.box { width: 100%; padding: 20px; }
3. Common Pitfalls & Solutions:

Pitfall: Layout overflow caused by padding additions. Solution: Apply global border-box rules.

4. Simulated Viva Dialogue:

👨‍🏫 Instructor: "Why use border-box?"

👩‍🎓 Student: "It prevents elements from expanding beyond their container when padding is applied."

Question 7 What is the standard Project Architecture for a static website?

1. Theoretical Foundation:

A flat root directory containing primary HTML pages accompanied by organized subdirectories like css/, js/, and images/.

2. Code Example:
project/ -> index.html, about.html, activities.html, css/style.css
3. Common Pitfalls & Solutions:

Pitfall: Nesting HTML pages causing broken relative paths. Solution: Keep primary pages flat in the root folder.

4. Simulated Viva Dialogue:

👨‍🏫 Instructor: "Why keep all main HTML files in the root folder?"

👩‍🎓 Student: "To ensure consistent navigation links and proper automated grading scanner detection."

Question 8 How do you implement Zebra Striping and Hover effects using CSS?

1. Theoretical Foundation:

Using tr:nth-child(even) for alternating row backgrounds and tr:hover for interactive cursor feedback.

2. Code Example:
tr:nth-child(even) { background-color: #f2f2f2; }
tr:hover { background-color: #e2e8f0; }
3. Common Pitfalls & Solutions:

Pitfall: Forgetting border-collapse: collapse. Solution: Always collapse table borders to avoid double lines.

4. Simulated Viva Dialogue:

👨‍🏫 Instructor: "What does nth-child(even) target?"

👩‍🎓 Student: "Even-indexed table rows to apply background styling for readability."

Question 9 What is the importance of Web Accessibility and the scope attribute in tables?

1. Theoretical Foundation:

Attributes like scope="col" or scope="row" help screen readers associate header cells with data cells correctly.

2. Code Example:
<th scope="col">Header Title</th>
3. Common Pitfalls & Solutions:

Pitfall: Using <td> instead of <th> for headers. Solution: Always use semantic header cells with scope.

4. Simulated Viva Dialogue:

👨‍🏫 Instructor: "How does scope help screen reader users?"

👩‍🎓 Student: "It declares how header cells govern data cells, announcing table coordinates clearly."

Question 10 What is the standard workflow for testing and deploying projects?

1. Theoretical Foundation:

Testing via local checkers, validating file layouts, and executing Git version control commands (`add`, `commit`, `push`) to publish online.

2. Code Example:
git add . && git commit -m "Update project" && git push
3. Common Pitfalls & Solutions:

Pitfall: 404 deployment errors due to incorrect homepage naming. Solution: Always name the root landing page `index.html`.

4. Simulated Viva Dialogue:

👨‍🏫 Instructor: "If your deployed link returns 404, what should you check?"

👩‍🎓 Student: "Whether the landing page is named index.html in the root directory and pushed successfully."
